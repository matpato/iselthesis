\section{Introduction} % (fold)
\label{sec:introduction}

This chapter describes how to use the \LaTeX{} class \texttt{iselthesis}. This class is a major rewrite of templates used in several universities, which were in turn adapted from the FCT-UNL template \cite{novathesis-manual}. We aimed at providing an improved visual layout and, simultaneously, a \emph{very easy to use} template (aka, a \LaTeX{} template for dummies).

The main design principle is simple: \textbf{you never edit the main file \texttt{template.tex} nor the class files}. Everything you need to change (document type, language, title, author, chapters, \ldots) is set in the small configuration files inside the \texttt{Config} directory.

\noindent%
\fbox{%
\begin{minipage}{\dimexpr\linewidth-2\fboxsep-2\fboxrule}
	\textbf{Text encoding.} All your \texttt{.tex} and \texttt{.bib} files \textbf{must} be saved in \textbf{UTF-8}. This is the default in all modern editors (Overleaf, TeXstudio, VS Code, TeXShop, \ldots). If accented characters (e.g., ``ç'', ``ã'') appear wrong in the PDF, check the encoding of the file in your editor.
\end{minipage}%
}
% section introduction (end)

A few notes:
\begin{itemize}
	\item \textbf{Excluding a file.} To leave a file out of the document, remove it from \texttt{Config/\_files.tex}, or rename it (e.g., \texttt{ganttdiagram\_.tex} instead of \texttt{ganttdiagram.tex}).
	\item \textbf{Statement.} The statement file is required for the final version of the master's dissertation (\texttt{docdegree=msc}). It exists in English and Portuguese; the one matching the main language of the document is used.
	\item \textbf{References.} An easy way to obtain BibTeX entries is to enable \texttt{Show links to import citation into Bib\-TeX} in the \href{http://scholar.google.pt/scholar_settings?hl=en&as_sdt=0,5}{Google Scholar settings}.
\end{itemize}

Again, we would like to recall that all your \LaTeX{} files should be stored in the \verb!Chapters! directory, and all the images in the \verb!Chapters/img! directory.

\section{Document Options} % (fold)
\label{sec:document_options}

The document options are \textbf{not} given in the \texttt{\textbackslash documentclass[\ldots]} line of \texttt{template.tex}. Instead, they are set in the file \texttt{Config/\_options.tex}, using the command \texttt{\textbackslash iselthesissetup}:

\begin{Verbatim}[breaklines=true, breakanywhere=true]
\iselthesissetup{
  docdegree      = msc,          % msc, mscprep, bsc
  doctype        = dissertation, % dissertation, project
  lang           = en,           % en, pt
  coverlang      = en,           % en, pt
  printcommittee = true,         % true, false
  media          = screen,       % screen, paper
  linkscolor     = darkblue,     % darkblue, black
}
\end{Verbatim}

Any option omitted from this file keeps its default value. Options are applied in the following order, and the last one wins:
\begin{enumerate}
	\item the institutional defaults (in \texttt{ISELthesis-files/options.clo});
	\item options given in \texttt{\textbackslash documentclass[\ldots]}, if any (kept only for compatibility with older versions of the template);
	\item the options in \texttt{Config/\_options.tex}.
\end{enumerate}

Some options are fixed by the institution, to guarantee that all documents follow the ISEL graphic guidelines, and should not be changed: the font (Verdana, or a similar sans-serif font), the chapter style (\texttt{isel}), the place of the lists of figures and tables (\texttt{front}) and the bibliography style (numeric, \texttt{biblatex}).

\subsection{Language Related Options} % (fold)
\label{sub:language_related_options}

You must choose the main language of the document (option \texttt{lang}). The available values are:

\begin{enumerate}
	\item \textbf{en} --- The document is written in English (with an abstract in Portuguese).
	\item \textbf{pt} --- The document is written in Portuguese (with an abstract in English).
\end{enumerate}

The language option affects:
\begin{itemize}
	\item \textbf{The order of the abstracts.} First the abstract in the main language and then the one in the other language. If the main language is English, you will see first the ``Abstract'' and then the ``Resumo''. If you switch the main language, the order is switched automatically.
	\item \textbf{The names of the document parts.} E.g., ``Chapter'' vs.\ ``Capítulo'', ``Contents'' vs.\ ``Índice'', ``Figure'' vs.\ ``Figura'', etc.
	\item \textbf{The labels in the bibliography.} E.g., ``Technical Report'' vs.\ ``Relatório Técnico'', ``MSc Thesis'' vs.\ ``Tese de Mestrado'', etc.
\end{itemize}

The option \texttt{coverlang} sets the language of the cover pages independently of the main language. In most cases it should be the same as \texttt{lang}.

No matter which language you choose, you will always have the appropriate hyphenation rules for the language in use at each point: Portuguese rules in the ``Resumo'', English rules in the ``Abstract'', and the main language rules in the rest of the document. If you need to force the hyphenation of a word, write it inside \verb!\hyphenation{}! in \texttt{Config/\_packages.tex}, e.g., \verb!\hyphenation{op-ti-cal net-works}!.

\subsection{Class of Text} % (fold)
\label{sub:class_of_text}

You must choose the class of text for the document (option \texttt{docdegree}). The available values are:

\begin{enumerate}
	\item \textbf{bsc} --- Bachelor's (BSc) project report. The second cover page includes signature lines for the author and the advisers.
	\item \textbf{mscprep} --- Preparation of the MSc dissertation. This is a preliminary report that ISEL/IPL master's students prepare to conclude the first semester of the two-semester MSc work. The files specified by 
	\begin{inparaenum}
		\item \verb!\dedicatoryfile!,
		\item \verb!\acknowledgementsfile! and
		\item \verb!\quotefile!
	\end{inparaenum}
	are ignored, even if present, for this class of document. There is no second cover page.
	\item \textbf{msc} --- MSc dissertation. Includes a second cover page with the advisers and the committee, and the statement and copyright pages.
\end{enumerate}

\subsection{Printing} % (fold)
\label{sub:printing}

You must choose the target media of your document (option \texttt{media}). The available values are:

\begin{enumerate}
	\item \textbf{screen}(*) --- For reading on screen: left and right margins are equal and hyperlinks are coloured;
	\item \textbf{paper} --- For printing: left and right margins are different (wider binding margin) and hyperlinks are black.
\end{enumerate}

Article 50 of Decree-Law No.~115/2013 requires the deposit of a digital copy of doctoral theses and master's dissertations in a repository that is part of RCAAP\footnote{Repositórios Científicos de Acesso Aberto de Portugal}, \url{https://www.rcaap.pt}. This deposit aims to preserve scientific work and to provide Open Access to scientific production that is not subject to restrictions or embargo.

For this reason, we include the option to format your document so that it presents well on screen and/or on paper. But always remember that your work will be stored in the RCAAP portal in electronic format.

\subsection{Draft and Final Versions} % (fold)
\label{ssec:draft_final}

The options of the base class \texttt{memoir} are set in \texttt{Config/\_memoir.tex}:

\begin{Verbatim}[breaklines=true, breakanywhere=true]
\ncmemoirsetup{a4paper,11pt,final}   % draft | final
\end{Verbatim}

While writing, you may use \texttt{draft}: the cover shows ``DRAFT'' and the current date. Replace it with \texttt{final} for the version you submit.

\subsection{Examples} % (fold)
\label{ssec:examples}

Let's have a look at a few examples of \texttt{Config/\_options.tex}:

\begin{itemize}
	\item BSc project report, in Portuguese, to be read on screen:
\begin{Verbatim}
\iselthesissetup{docdegree=bsc, lang=pt, coverlang=pt}
\end{Verbatim}
	\item Preparation of the MSc dissertation, in Portuguese, with black links:
\begin{Verbatim}
\iselthesissetup{docdegree=mscprep, lang=pt, coverlang=pt,
                 linkscolor=black}
\end{Verbatim}
	\item MSc project, in English, to be printed on paper:
\begin{Verbatim}
\iselthesissetup{docdegree=msc, doctype=project, lang=en,
                 coverlang=en, media=paper, linkscolor=black}
\end{Verbatim}
\end{itemize}

The present document uses the following \texttt{Config/\_options.tex}:
\begin{Verbatim}[breaklines=true, breakanywhere=true]
\iselthesissetup{
  docdegree      = msc,
  doctype        = dissertation,
  lang           = pt,
  coverlang      = pt,
  printcommittee = true,
  media          = screen,
  linkscolor     = darkblue,
}
\end{Verbatim}

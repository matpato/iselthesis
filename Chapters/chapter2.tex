\section{Introduction} % (fold)
\label{sec:introduction}

This chapter describes how to use the \LaTeX{} class \texttt{iselthesis}. This class is a major rewrite of templates used in several universities, which were in turn adapted from the FCT-UNL template \cite{novathesis-manual}. We aimed at providing an improved visual layout and, simultaneously, a \emph{very easy to use} template (aka, a \LaTeX{} template for dummies).

The main design principle is simple: \textbf{you never edit the main file \texttt{template.tex} nor the class files}. Everything you need to change (document type, language, title, author, chapters, \ldots) is set in the small configuration files inside the \texttt{Config} directory.

\noindent%
\fcolorbox{iselorange}{white}{%
\begin{minipage}{\dimexpr\linewidth-2\fboxsep-2\fboxrule}
	\textbf{Text encoding.} All your \texttt{.tex} and \texttt{.bib} files \textbf{must} be saved in \textbf{UTF-8}. This is the default in all modern editors (Overleaf, TeXstudio, TeXmaker, VS Code, TeXShop, \ldots). If accented characters (e.g., ``ç'', ``ã'') appear wrong in the PDF, check the encoding of the file in your editor.
\end{minipage}%
}
% section introduction (end)

A few notes:
\begin{itemize}
	\item \textbf{Excluding a file.} To leave a file out of the document, remove it from \texttt{Config/\_files.tex}, or rename it (e.g., \texttt{ganttdiagram\_.tex} instead of \texttt{ganttdiagram.tex}).
	\item \textbf{Integrity declaration.} For the final master's dissertation (\texttt{docdegree=msc}) the integrity declaration (statement page) is filled in automatically, in the main language of the document. You only need to set its date in \texttt{Config/\_cover.tex} (Section~\ref{sec:cover_data}).
	\item \textbf{References.} An easy way to obtain BibTeX entries is to enable \texttt{Show links to import citation into Bib\-TeX} in the \href{http://scholar.google.pt/scholar_settings?hl=en&as_sdt=0,5}{Google Scholar settings}.
\end{itemize}

\section{Document Options} % (fold)
\label{sec:document_options}

The document options are \textbf{not} given in the \texttt{\textbackslash documentclass[\ldots]} line of \texttt{template.tex}. Instead, they are set in the file \texttt{Config/\_options.tex}, using the command \texttt{\textbackslash iselthesissetup}:

\begin{Verbatim}[breaklines=true, breakanywhere=true]
\iselthesissetup{
  docdegree      = msc,          % msc, mscprep, bsc
  doctype        = dissertation, % dissertation, project
  lang           = en,           % en, pt
  coverlang      = en,           % en, pt
  printcommittee = true,         % true, false
  media          = screen,       % screen, paper
  linkscolor     = darkblue,     % darkblue, black
}
\end{Verbatim}

Any option omitted from this file keeps its default value. Options are applied in the following order, and the last one wins:
\begin{enumerate}
	\item the institutional defaults (in \texttt{ISELthesis-files/options.clo});
	\item options given in \texttt{\textbackslash documentclass[\ldots]}, if any (kept only for compatibility with older versions of the template);
	\item the options in \texttt{Config/\_options.tex}.
\end{enumerate}

Some options are fixed by the institution, to guarantee that all documents follow the ISEL graphic guidelines, and should not be changed: the font (Verdana), the chapter style (\texttt{isel}), the place of the lists of figures and tables (\texttt{front}) and the bibliography style (numeric, \texttt{biblatex}).

\subsection{Language Related Options} % (fold)
\label{sub:language_related_options}

You must choose the main language of the document (option \texttt{lang}). The available values are:

\begin{enumerate}
	\item \textbf{en} --- The document is written in English (with an abstract in Portuguese).
	\item \textbf{pt} --- The document is written in Portuguese (with an abstract in English).
\end{enumerate}

The language option affects:
\begin{itemize}
	\item \textbf{The order of the abstracts.} First the abstract in the main language and then the one in the other language.
	\item \textbf{The names of the document parts.} E.g., ``Chapter'' vs.\ ``Capítulo'', ``Contents'' vs.\ ``Índice'', ``Figure'' vs.\ ``Figura'', etc.
	\item \textbf{The labels in the bibliography.} E.g., ``Technical Report'' vs.\ ``Relatório Técnico'', ``MSc Thesis'' vs.\ ``Tese de Mestrado'', etc.
	\item \textbf{The PDF metadata} (title and language of the document).
\end{itemize}

The option \texttt{coverlang} sets the language of the cover pages independently of the main language. In most cases it should be the same as \texttt{lang}.

No matter which language you choose, you will always have the appropriate hyphenation rules for the language in use at each point. If you need to force the hyphenation of a word, write it inside \verb!\hyphenation{}! in \texttt{Config/\_packages.tex}, e.g., \verb!\hyphenation{op-ti-cal net-works}!.
% subsection language_related_options (end)

\subsection{Class of Text} % (fold)
\label{sub:class_of_text}

You must choose the class of text for the document (option \texttt{docdegree}). The available values are:

\begin{enumerate}
	\item \textbf{bsc} --- Bachelor's (BSc) project report. The second cover page includes signature lines for the authors and the advisers. Up to three authors are supported.
	\item \textbf{mscprep} --- Preparation of the MSc dissertation. This is a preliminary report that ISEL/IPL master's students prepare to conclude the first semester of the two-semester MSc work. The files specified by 
	\begin{inparaenum}
		\item \verb!\dedicatoryfile!,
		\item \verb!\acknowledgementsfile! and
		\item \verb!\quotefile!
	\end{inparaenum}
	are ignored, even if present, for this class of document. There is no second cover page.
	\item \textbf{msc} --- MSc dissertation. Includes a second cover page with the advisers and the committee, the integrity declaration and the copyright page.
\end{enumerate}
% subsection class_of_text (end)

\subsection{Printing} % (fold)
\label{sub:printing}

You must choose the target media of your document (option \texttt{media}). The available values are:

\begin{enumerate}
	\item \textbf{screen}(*) --- For reading on screen: left and right margins are equal, hyperlinks are coloured and there are no blank pages;
	\item \textbf{paper} --- For printing: left and right margins are different (wider binding margin), hyperlinks are black and chapters start on a right-hand page.
\end{enumerate}

Article 50 of Decree-Law No.~115/2013 requires the deposit of a digital copy of doctoral theses and master's dissertations in a repository that is part of RCAAP\footnote{Repositórios Científicos de Acesso Aberto de Portugal}, \url{https://www.rcaap.pt}. This deposit aims to preserve scientific work and to provide Open Access to scientific production that is not subject to restrictions or embargo. For this reason, the template always produces a \textbf{PDF/A} file, the archival format required by repositories.

\subsection{Draft and Final Versions} % (fold)
\label{ssec:draft_final}

The options of the base class \texttt{memoir} are set in \texttt{Config/\_memoir.tex}:

\begin{Verbatim}[breaklines=true, breakanywhere=true]
\ncmemoirsetup{a4paper,11pt,draft}   % draft | final
\end{Verbatim}

While writing, use \texttt{draft}. Compilation is faster and helps you find layout problems:
\begin{itemize}
	\item the first page of the PDF is a \textbf{checklist} of everything you must verify before submitting;
	\item the first cover is shown (with its background), but the second cover is omitted;
	\item images in the text are replaced by boxes with the file name;
	\item lines that are too long (overfull) are marked with black bars;
	\item the cover shows ``DRAFT'' and the current date.
\end{itemize}

Replace \texttt{draft} with \texttt{final} for the version you submit. The checklist disappears and the document is complete.

Let's have a look at a few examples of \texttt{Config/\_options.tex}:

\end{itemize}

\section{Cover Data and PDF Metadata} % (fold)
\label{sec:cover_data}

All the personal data of your document is set in \texttt{Config/\_cover.tex}. It is used in the covers, in the integrity declaration, in the copyright page and in the PDF metadata. \textbf{You write it only once.}

\subsection{Authors, Title and Course} % (fold)
\label{ssec:authors_title_course}

\begin{Verbatim}[breaklines=true, breakanywhere=true]
% Author: (m|f){Full name}{Short name} -- repeat for up to 3 authors (BSc)
\ncauthorname(m){John Very Longname Doe}{John Doe}

% Title in both languages (use \\ to break the line on the cover)
\nctitle(main,en){Title of the Dissertation}
\nctitle(main,pt){Título da Dissertação}

% Course (acronym from the table of course acronyms)
\iselthesis@setcourse{meic}
\end{Verbatim}

The course acronym sets the name of the course, the department and the cover images automatically. \tablename~\ref{tab:courses} lists the available acronyms. The same acronym is used for bachelor's and master's documents: with \texttt{docdegree=bsc} the cover automatically refers to the bachelor's degree, so there is no separate acronym for bachelor's courses.

\subsection{Advisers, Committee and Dates} % (fold)
\label{ssec:advisers_committee_dates}

\begin{Verbatim}[breaklines=true, breakanywhere=true]
% (role,gender){Name}{Affiliation}
%   role: a = adviser, c = president, r = member
\ncmember(a,f){Name of the Adviser}{ISEL}
\ncmember(c,m){Name of the President}{ISEL}
\ncmember(r,f){Name of the Member}{University}

% Date of the cover and of the integrity declaration
\dateday{30}
\datemonth{6}
\dateyear{2026}
\end{Verbatim}

The committee is printed only on the second cover of the final MSc dissertation, and only if \texttt{printcommittee=true}.

\subsection{Keywords and PDF Metadata} % (fold)
\label{ssec:keywords_metadata}

\begin{Verbatim}[breaklines=true, breakanywhere=true]
% Keywords for the PDF metadata (comma-separated, same as in the abstract)
\nckeywords{keyword1, keyword2, keyword3}
\end{Verbatim}

The template produces a \textbf{PDF/A} file, which includes metadata: author, title, subject, keywords, language and copyright. This metadata is \textbf{generated automatically} from \texttt{Config/\_cover.tex} and \texttt{Config/\_options.tex}; you do not need to edit any other file.

The metadata is written during one compilation and included in the PDF in the next one. Since a complete build always compiles more than once, this is transparent. To confirm, open the PDF and check \emph{File} $\rightarrow$ \emph{Properties}: the title, author, subject and keywords must match your data.

ISELthesis — Changelog

*2026-10-21 — Version 4.3.2
Configuration
+ Document options moved from \documentclass[...] to Config/_options.tex,
  set with the new \iselthesissetup{...} command; template.tex is now just
  \documentclass{iselthesis} and no longer needs to be edited
+ Option precedence: defaults (options.clo) -> \documentclass -> Config/_options.tex
+ memoir options (a4paper, 11pt, draft/final) set only in Config/_memoir.tex
  via \ncmemoirsetup (the memoir={} key was applied after memoir was loaded)
Compilation
+ LuaLaTeX is now the required engine (Verdana font); pdfLaTeX compiles
  with a Helvetica-like fallback
Documentation
+ Abstracts (PT/EN) rewritten: purpose of the template and the three
  essential rules (LuaLaTeX, edit only Config/Chapters, do not touch
  the class files)
+ Chapter 2: options described via Config/_options.tex; folder structure
  as a table with an "Edit?" column, including ISELthesis-files contents;
+ Chapter 3: LuaLaTeX warning box; compilation section rewritten
  (lualatex/bibtex, latexmk, editor settings, font check); expected
  document structure as a three-column table; removed latex/DVI/EPS content
+ README rewritten: three rules at the top, step-by-step setup,
  updated file tree and compilation instructions

*2026-05-04 — Version 4.3.1
+ Font loading via Font-Styles/*.ldf files; added verdana.ldf
+ Semantic colour commands replace hardcoded iselorange/iselpurple
+ \cleardoublepage and openany/openright depend on the media option
  (screen = no blank pages, paper = original behaviour)
+ Draft mode passes draft to graphicx and shows \printchecklist;
  fixed draft/final conflict in \ExecuteOptionsX
+ Support for up to 3 authors, with signature lines on the BSc second cover
+ Fixed unconditional loading of gillius2; \parskip/\parindent moved to isel.ldf

*2026-04-29 — Version 4.3
+ Verdana as main font (fontspec for LuaLaTeX/XeLaTeX, helvet fallback
  for pdfLaTeX); engine detection and microtype settings per engine
+ New heading styles: chapters 14pt bold uppercase orange; sections 12pt
  and subsections 11pt bold purple
+ Captions 9pt, black, Verdana (figures italic, tables regular)
+ Paragraphs: no extra spacing, 16pt indentation
+ Single spacing in bibliography, appendices and annexes
+ No blank pages (\clearpage instead of \cleardoublepage, openany)

*2026-03-07 — Version 4.2
+ Course data (major field, department, cover images) set from a single
  acronym with \iselthesis@setcourse{}; \ncdepartment and \ncmajorfield removed
+ Config/_department.tex replaced by Config/_institution.tex
  (university and school names only)
+ Cover text: optional specialization area, language-aware date
  ("of"/"de"), gender-aware pronoun for project/dissertation
+ New \dateday command for the statement signature date
+ Logo for the Biomedical Engineering master's degree
